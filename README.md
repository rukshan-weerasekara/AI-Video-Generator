# 🎥 AI Video Generator 

An innovative web application that transforms text descriptions into short, high-quality AI-generated videos. Built using **Python**, **Streamlit**, and the **Hugging Face Inference API**.

## 🚀 Features
* **Text-to-Video:** Bring your imagination to life with AI-powered motion.
* **Model Integration:** Utilizes the **ModelScope Text-to-Video** model for realistic results.
* **Instant Preview:** Watch your generated video directly within the app.
* **Downloadable Content:** Save your AI videos in MP4 format with ease.
* **Minimalist UI:** Designed for a smooth and creative user experience.

## 🛠️ Tech Stack
* **Language:** [Python](https://www.python.org/)
* **Framework:** [Streamlit](https://streamlit.io/)
* **AI Model:** [ModelScope 1.7B](https://huggingface.co/damo-vilab/text-to-video-ms-1.7b) via Hugging Face API
* **Libraries:** `requests`, `time`
